# EdgeHub v1.0.0

Release version: `v1.0.0`
Release stage: stable

EdgeHub 1.0 is a readability, fidelity, and reliability release for the
native Linux dashboard and its companion Manager. Every first-party widget has
been revisited at its supported sizes, the Manager now mirrors the Hub more
faithfully, and release verification covers compiled QML resources, runtime
recovery, package lifecycles, and visual baselines.

## See it in action

Watch the [71-second live Hub and Manager product film](https://github.com/skyphoenix-it/skyphoenix-edgehub-linux/releases/download/v1.0.0-beta.1/edgehub-v1.0.0-beta.1-live-product-film.mp4).
The film was captured from the signed beta.1 product and shows the running Hub change
screens, turn between landscape and portrait while Manager follows the same
orientation, receive a new screen and widget from Manager, change the page
layout, apply an Aurora theme and purple accent, switch the Manager to dark
mode, and change a Device preference. The front bezel and camera presentation
are editorial; every pixel inside both screens is synchronized output from the
real applications. The 1.0 release keeps that workflow and adds the widget,
preview, readability, and recovery refinements described below.

The separate [45-second theme and accent showcase](https://github.com/skyphoenix-it/skyphoenix-edgehub-linux/releases/download/v1.0.0-beta.1/edgehub-v1.0.0-beta.1-manager-theme-showcase.mp4)
shows all 20 themes included in Free and ten representative accent colours.
Both films include an original, sample-free ambient
soundtrack generated by the repository's audio script.

## Highlights

- 30 first-party widgets and 19 preset screens, plus a separate landscape visual reference.
- Touch-first portrait and landscape dashboards.
- EdgeHub Manager can add, resize, reorder, restyle, and switch the screen shown
  by the running Hub over a local socket.
- Real widget previews in the preset picker, including audience and purpose
  guidance before a screen is added.
- Per-size widget layouts with shared legibility, contrast, density, and touch
  rules.
- Truthful history charts with readable value and time axes, preserved raw
  peaks, smooth trends, and selectable line or bar presentations.
- Preset previews that follow the live Hub orientation and use the exact
  non-overlapping packed layout before a screen is added.
- Smooth rotation with bounded startup HID retries and live Manager reflection.
- Optional immersive Hub navigation while widget-specific settings remain
  available on the panel.
- Persistent, high-visibility Hub alerts for Break, Focus, and medication
  reminders, with deliberate acknowledge, snooze, review, and dismiss actions.
- 29 themes, 29 accents, 10 animated backgrounds plus Gradient, and 18 bundled
  wallpapers.
- Local TOML configuration, no account requirement, and no telemetry
  implementation.
- All functional features, widgets, presets, layouts, backgrounds, wallpapers,
  accessibility options, and the Manager are available in Free.
- Pro entitlement is limited to nine optional colour themes; Pro keys are not
  sold as part of this release.

## Verification summary

The release product tree passed Rust formatting, Clippy, 341 Rust tests, the
95% Rust coverage gate, compiled-resource Qt 6.7 QML tests, all enumerated QML
requirements, C++ tests and runtime E2E, the 95% C++ coverage gate, build,
CodeQL, supply-chain checks, and network containment.

The hosted compositor duplicate was cancelled after 30 minutes to stop wasting
GitHub Actions time. It is reported as cancelled, not passed. The same complete
suite ran locally on clean product candidate `400f374`: 2,641 assertions
passed, 0 failed, and 0 skipped across 22 files. Its 1,347 evidence files are
retained under the full commit SHA with a signed manifest. The stable tag adds
only release documentation and distribution-workflow corrections to that
tested product tree.

The owner confirmed that physical panel input works but did not complete the
scripted nine-action physical-touch audit. That certificate is reported as not
tested, not passed. The owner also waived the planned 30-minute instrumented
performance observation and the earlier 48-hour soak. This release therefore
makes no formal performance, resource-slope, physical-touch certification, or
long-duration stability claim.

## Known limitations

- Auto-rotate needs the included udev rule; manual orientation works without it.
- The release does not embed an on-screen keyboard. Text entry requires a
  physical keyboard or an input method provided by the desktop environment.
- Network widgets require explicit configuration and remain subject to the
  central egress gate.
- No stable AUR package or Flatpak is published with 1.0. The committed AUR
  recipe remains pinned to beta.1.
- The scripted physical-touch certificate and formal performance measurements
  were not completed and are not claimed.
- Keep a copy of `~/.config/xeneon-edge-hub/config.toml` before upgrading. The
  supported installers also create a timestamped backup automatically.
